## 🏀 NBA Rookie App

Aplicación desarrollada con **Ionic + Angular** para explorar jugadores de la NBA, guardar favoritos y gestionar autenticación mediante Firebase. Esta app está dividida en niveles de desarrollo, donde en cada carpeta se encuentra el nivel correspondiente.

---

## 🔐 Instrucciones de Uso

### 1. Crear nueva cuenta

Puedes registrarte desde la pantalla de registro de la aplicación utilizando un email y una contraseña válidos.

### **Nivel 1: Creación de la app y componentes básicos 
Implementar página de login.
Implementar página de registro.
Implementar página de lista de jugadores. Para cada jugador mostraremos nombre, apellidos, altura, peso y nombre del equipo en el que juega. En la esquina superior derecha de la página tendrá que aparecer un botón de una cámara y un botón de compartir en cada jugador.
Implementar página de detalle de cada jugador dónde también podremos marcarlo como favorito. En este apartado mostraremos más información como el país, número de jugador y posición.


Nivel 2: Consumo de una API externa (2 puntos)
Recuperar datos de la API pública de la NBA (https://www.balldontlie.io/) y utilizarlos para la lista de jugadores.
Utilizar servicios inyectables para separar la lógica de la API del componente.
